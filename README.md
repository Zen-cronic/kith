# Household (working name) — a Strands Agents household authority agent

> Built with the **Strands Agents SDK** (`strands-agents` 1.54.0, `bidi` extra) and Amazon Bedrock (Nova Pro for vision, Nova 2 Lite for reasoning, Nova 2 Sonic for voice) for the AWS **Agents for Humans** hackathon, Everyday Agents track. MIT licensed.

Every member of the household — including the kids — talks to it or shows it a photo. It knows exactly who may decide what for whom, does the work it is allowed to do and proves it with a receipt, routes the rest to the right parent for one tap, and publishes the number that matters: **0 out-of-scope actions executed across N adversarial requests, with a measured false-refusal rate.**
